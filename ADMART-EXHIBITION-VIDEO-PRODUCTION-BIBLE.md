## 1. Document Overview

### 1.1 What This Document Is

This is the **single source of truth** for all exhibition video content for Admart. It defines:

- **What videos** to produce
- **What each video says** (full scripts, word for word)
- **What appears on screen** (every scene, every screen, every graphic)
- **How videos are displayed** at the booth
- **How staff should talk** when visitors watch or ask questions

### 1.2 What This Document Is Not

- It is not a prompt list for AI tools alone — it is a **full production specification**
- It does not replace the product profile (`ADMART-PROJECT-PROFILE.md`) — it **uses** that content for customer-facing storytelling
- AI video generation may be used for branding B-roll, but the **product demo must show the real Admart application**

### 1.3 Success Criteria

At the exhibition, a visitor should be able to:

1. **Understand what Admart is** within 10 seconds (branding loop)
2. **Feel the problem Admart solves** within 60 seconds (solution video)
3. **See exactly how it works** within 2 minutes (demo video)
4. **Know what to do next** — scan QR, sign up free, talk to staff

## 3. Who Will Watch These Videos

### 3.1 Visitor Personas at the Booth

| Persona | What They Care About | Which Video Matters Most |
|---------|---------------------|--------------------------|
| **Solo creator / influencer** | Speed, captions, multi-platform, cost | Demo + Solution |

- **Looping** — videos repeat endlessly; first and last frame must connect smoothly

## 6. Brand Guidelines for Video

### 6.1 Logo

| Element | Specification |
|---------|---------------|
| Logo mark | Gradient letter **"A"** inside rounded square |
| Gradient | Blue `#2563eb` → Violet `#7c3aed` |
| Clear space | Minimum 1× logo height on all sides |
| On dark background | Full color gradient logo |
| On light background | Use dark logo variant or place on dark panel |
| Minimum size on video | 120px width at 1080p |

### 6.2 Color Palette

| Token | Hex | Use in Video |
|-------|-----|--------------|
| Base (background) | `#09090b` | Primary video background |
| Panel | `#18181b` | Cards, UI panels in motion graphics |
| Surface | `#27272a` | Secondary panels |
| Accent Blue | `#2563eb` | Highlights, CTAs, key words |
| Accent Violet | `#7c3aed` | Gradients, secondary highlights |
| Text Primary | `#fafafa` | Headlines, body on dark |
| Text Secondary | `#a1a1aa` | Subtitles, supporting text |
| Success | `#22c55e` | Published status, positive metrics |
| TikTok | Platform token | Platform icons only |
| YouTube | Platform token | Platform icons only |
| Instagram | Platform token | Platform icons only |
| Facebook | Platform token | Platform icons only |

### 6.3 Typography

| Role | Font | Weight | Size at 1080p |
|------|------|--------|---------------|
| Headlines | Syne | Bold (700) | 64–96px |
| Subheadlines | Syne | SemiBold (600) | 40–56px |
| Body / captions | DM Sans | Medium (500) | 32–40px |
| Data / timecodes | JetBrains Mono | Regular | 24–28px |
| CTA buttons | DM Sans | SemiBold | 36px |

### 6.4 Visual Style

- **Mood:** Premium SaaS, dark theme, confident, modern
- **Lighting:** Soft rim light, blue-violet glow, avoid flat lighting
- **Motion:** Smooth easing (ease-in-out), no jarring cuts in branding
- **UI shots:** Show real Admart dark UI — never mock up fake interfaces for demo
- **People:** Diverse, professional, aspirational — creators and marketers, not actors in suits only
- **Pace:** Branding = cinematic slow; Demo = clear and deliberate; Solution = emotional arc

### 6.5 Platform Icons

When showing supported platforms, always show all four in this order:

1. TikTok  
2. YouTube  
3. Instagram  
4. Facebook  

Use official platform colors on icon badges only — do not redesign logos.

5. **Brand Kit** applies your logo, colors, fonts, and tone to every video.
6. **Publish or schedule** to TikTok, YouTube, Instagram, and Facebook from one screen.
7. **Library, calendar, and analytics** — everything in one workspace.

### 12.3 Outcome Statements

1. Ship content **weekly without a production crew**.

3. **Start free** — 5 credits, no credit card.
