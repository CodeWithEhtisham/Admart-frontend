## 1. Executive Summary

**Admart** is an AI-powered video automation platform that helps creators, marketers, and teams produce, manage, and distribute short-form and long-form video content across multiple social channels from a single dashboard.

Instead of juggling separate tools for scripting, editing, captioning, voiceover, resizing, SEO optimization, and multi-platform publishing, Admart unifies the entire workflow: **from idea to published video in minutes, not days.**

**In one sentence:**  
*Turn ideas into platform-ready clips with AI generation, smart captions, and one-click publishing across TikTok, YouTube, Instagram, and Facebook.*

**Core promise:**  
Create AI videos. Publish everywhere. Instantly.

---

## 2. What Is Admart?

Admart is a **full-stack video content automation platform** built for the modern creator economy and digital marketing landscape. It combines:

- **AI video generation** (text-to-video, image-to-video)
- **AI image generation** (text-to-image, image-to-image)
- **Post-production automation** (voiceover, captions, music, encoding)
- **Platform-aware optimization** (aspect ratios, SEO tags, per-channel metadata)
- **Multi-channel publishing** (schedule or publish live to connected social accounts)
- **Content operations** (library, calendar, analytics, brand kit, billing)

The platform is designed for **speed, consistency, and scale** — enabling individuals and teams to ship scroll-stopping video content weekly without a full production crew.

### What Admart Does

| Capability | Description |
|------------|-------------|
| **Create** | Generate videos and images from text prompts, still images, or templates |
| **Enhance** | Add AI voiceover, smart captions, music, and brand overlays automatically |
| **Optimize** | Produce platform-specific variants (9:16, 16:9, 1:1, 4:5) with SEO-tuned titles and hashtags |
| **Publish** | Push or schedule content to TikTok, YouTube, Instagram, and Facebook |
| **Manage** | Organize assets in a video library, plan on a content calendar, track performance |
| **Brand** | Apply consistent logos, colors, fonts, and tone of voice across all generated content |

### What Admart Is Not

- Not a traditional non-linear video editor (like Premiere or Final Cut) — it is **automation-first**
- Not a single-platform tool — it is built for **cross-platform distribution**
- Not a generic AI chat tool — it is a **purpose-built video production and publishing pipeline**

## 4. The Problem We Solve

### 4.1 The Content Creation Bottleneck

Creating quality video content for social media is **slow, expensive, and fragmented**:

| Pain Point | Reality Today |
|------------|---------------|
| **Time** | A single 30-second promo can take hours between scripting, filming, editing, and exporting |
| **Cost** | Hiring editors, voice talent, and motion designers does not scale for daily posting |
| **Tool sprawl** | Creators use 5–10 separate tools: script AI, image gen, video editor, caption tool, scheduler, analytics |
| **Platform fragmentation** | Each platform has different aspect ratios, length limits, caption styles, and SEO conventions |
| **Inconsistent branding** | Without a system, videos look different every time — hurting brand recognition |
| **Publishing friction** | Uploading the same video to four platforms manually is repetitive and error-prone |
| **No single source of truth** | Assets live in folders, DMs, and cloud drives with no unified library or calendar |

### 4.2 Who Feels This Pain?

- **Solo creators** who need to post consistently but lack production resources
- **Small business owners** who know video drives sales but cannot afford an agency
- **Marketing teams** managing multiple brands across multiple social channels
- **Agencies** producing high volumes of client content under tight deadlines
- **E-commerce brands** needing product videos, promos, and tutorials at scale

### 4.3 The Opportunity

Short-form video dominates attention on TikTok, Instagram Reels, YouTube Shorts, and Facebook. Brands that post consistently win algorithm favor — but **consistency requires automation**. Admart exists to close the gap between *having ideas* and *shipping videos everywhere those ideas need to live*.

## 5. Our Solution

Admart provides an **end-to-end video automation pipeline** in one workspace:

```
Idea → AI Generation → Enhancement → Review → Publish → Analyze
```

### Solution Pillars

1. **AI-First Creation** — Describe what you want; the platform structures a shot plan and generates video automatically
2. **One Asset, Many Platforms** — A single “asset graph” produces variants optimized for each channel
3. **Brand-Aware Output** — Brand Kit settings (logo, colors, fonts, tone) apply to every generation
4. **Unified Operations** — Dashboard, library, calendar, and analytics in one place
5. **Credit-Based Simplicity** — Transparent usage pricing; pay for what you generate

## 6. How It Works

### The Three-Step Flow (Customer-Facing)

| Step | Name | What Happens |
|------|------|--------------|
| **01** | **Type Your Idea** | User describes hook, audience, and tone. Admart structures a shot plan automatically |
| **02** | **AI Generates** | Clips, captions, voiceover, and platform variants are produced in parallel |
| **03** | **Auto-Publish** | User reviews, then schedules or pushes live to every connected channel |

### Detailed Creation Wizard (4 Steps)

The **Create Video** wizard (`/create`) walks users through:

1. **Input** — Choose input mode and provide source material
2. **Configure** — Set aspect ratio, resolution, style, AI model, and target platforms
3. **Enhance** — Add voiceover, captions, music, and creative suggestions
4. **Generate** — Submit job; track progress; review result

### Generation Progress Pipeline

When a video is generating, the system progresses through these stages:

1. Analyzing Prompt
2. Generating Frames
3. Rendering Video
4. Adding Music
5. Burning Captions
6. Encoding Output

Users can watch real-time progress or receive a notification when complete.

### Post-Generation Flow

```
/create → /progress → /result → /publish → /dashboard
```

After generation, users preview the result, optionally edit metadata per platform, then publish immediately or schedule for later.

## 7. Core Features (Detailed)

### 7.1 Text to Video

- Prompt-to-timeline generation with **scene-aware pacing**
- User describes concept; AI builds visual narrative
- Supports creative suggestions: cinematic transitions, slow motion, text overlays, product showcase, CTA endings
- Multiple AI video models with different quality/speed/credit tradeoffs

### 7.2 Image to Video

- Animate still images and product shots with **motion presets**
- Ideal for e-commerce, product launches, and brand storytelling from existing photography
- Combines uploaded or AI-generated images with motion and narration

### 7.3 Text to Image

- Generate source images from text prompts for use in video pipelines
- Integrated into the creation wizard as a standalone or preparatory step
- Async job-based generation with status polling

### 7.4 Image to Image

- Transform and enhance existing images (style transfer, background cleanup, composition)
- Useful for adapting product shots to brand guidelines before animating

### 7.5 Upload & Modify

- Upload existing video or image assets and apply AI modifications
- Extends platform value beyond pure generation — supports hybrid workflows

### 7.6 Template-Based Creation

- **48+ templates** across categories:
  - Product Ads
  - Social Stories
  - Testimonials
  - Promos
  - Announcements
  - Education
  - E-commerce
- Each template specifies: aspect ratios, duration range, voiceover options, music pack, credit cost, and supported platforms
- Premium and free templates available
- One-click start from template into the creation wizard

### 7.7 AI Voiceover

- Natural-sounding AI voices
- **SSML control** for pronunciation and emphasis
- Loudness-normalized audio masters
- Voice style options: Auto, Neutral, Warm, Energetic
- Credit cost: ~0.5 credits per use

### 7.8 Smart Captions

- **Word-level timing** synchronized to speech
- Emoji emphasis and kinetic typography
- **Safe-area layouts** respecting platform UI overlays (notches, buttons)
- Burned into final export or available as sidecar depending on platform
- Credit cost: ~0.5 credits per use

### 7.9 Auto SEO Tags

- AI-generated **titles, descriptions, and hashtags** tuned per platform
- Reduces manual metadata work during publishing
- Improves discoverability on YouTube, TikTok, and Instagram

### 7.10 Cross-Platform Publish

- One asset graph → outputs for **TikTok, YouTube, Instagram, and Facebook**
- Per-platform toggles during publish flow
- Per-platform metadata editing (title, description, tags)
- Publish now or schedule for later

### 7.11 Video Library

- Central repository for all generated and published videos
- Filter by status: All, Published, Ready, Scheduled, Generating, Failed
- View platform distribution, duration, views, and dates
- Download assets; retry failed generations

### 7.12 Content Calendar

- Visual schedule of published, scheduled, generating, and failed content
- Platform-coded events (TikTok, YouTube, Instagram, Facebook)
- Drag-and-plan content strategy across the month

### 7.13 Dashboard

- At-a-glance workspace home
- KPI cards: credits remaining, videos created, total views, scheduled posts

## 11. Workspace & Project Model

### Mental Model

```
User ──owns──> Project (many) ──has──> SocialAccount (many)
                              └──has──> Brand Kit / settings
                              └──has──> Videos / assets
```

### Key Concepts

| Concept | Description |
|---------|-------------|
| **User** | Account holder with plan, credits, and authentication |
| **Project** | A workspace for one brand, campaign, or client. Has its own social accounts, brand kit, and video library |
| **Active Project** | The project currently in focus; persisted server-side across sessions |
| **Social Account** | OAuth-connected platform account scoped to a project (not global per user) |
| **Brand Kit** | Per-project brand identity: logo, colors, fonts, tone, default generation settings |

### Why Projects Matter

- A marketing manager can run **“Summer Campaign”** and **“Product Launch”** as separate projects
- An agency can isolate **client A** and **client B** with different brand kits and social connections
- Switching project switches the **entire working context** — accounts, assets, and settings

### Project Properties

- Name (required, 1–80 characters)
- Icon (emoji/glyph)
- Color (hex)
- Organization label (e.g., “Personal”, “Admart”)
- Brand kit fields
- Last accessed timestamp (for recency ordering)

## 12. Technology & Architecture

### 12.1 System Overview

Admart is a **full-stack platform** with separated frontend and backend repositories:

| Layer | Technology |
|-------|------------|
| **Frontend** | React 19, Vite 8, React Router 7, Tailwind CSS 4 |
| **Backend** | Django + Django REST Framework (separate repo) |
| **API** | REST JSON API; OpenAPI schema for type generation |
| **Auth** | JWT (access + refresh tokens); Google OAuth |
| **Social OAuth** | Redirect-based OAuth for YouTube (Google), Facebook/Instagram (Meta) |
| **AI Inference** | Video: Mochi, CogVideoX, Wan 2.1 · Images via fal.ai: Flux, Nano Banana, Ideogram, GPT Image 2 |
| **Infrastructure** | GPU-backed generation (e.g., DGX-class hardware for image jobs) |

### 12.2 Frontend Application Structure

```
src/
├── App.jsx                 # Route definitions
├── main.jsx                # Entry + BrowserRouter
├── components/             # Shared UI (sidebar, layout, topbar)
├── pages/                  # Feature pages (dashboard, wizard, publish, etc.)
├── utils/                  # API client, projects, assets, user state
└── assets/                 # Static images and icons
```

### 12.3 API Integration

- Base URL: `VITE_API_URL` / `VITE_ADMART_API_URL` (default `http://localhost:8000`)
- All authenticated endpoints use `Authorization: Bearer <accessToken>`
- Project-scoped resources: `/api/projects/:id/...`
- Social OAuth: backend handles token exchange; frontend only redirects to authorize URL

### 12.4 Key API Domains

| Domain | Endpoints (examples) |
|--------|---------------------|
| Auth | `POST /api/auth/login`, `POST /api/auth/register`, `GET /api/auth/me` |
| Onboarding | `POST /api/auth/onboarding/complete` |
| Projects | `GET/POST /api/projects`, `PATCH/DELETE /api/projects/:id`, `POST /api/projects/:id/activate` |
| Social | `GET .../social/connect/:platform/url`, `GET .../social/accounts`, `DELETE .../social/disconnect/:platform` |
| Images | `POST /api/images/text-to-image`, `GET /api/images/text-to-image/:jobId` |
| Videos | Generation, status, and publish endpoints (backend-owned contract) |

### 13.4 Job Lifecycle

1. User submits generation request
2. Backend queues job → returns `job_id`
3. Frontend polls status: `queued` → `processing` → `done` | `error`
4. On completion: asset URL returned; saved to library
5. Credits deducted based on model and enhancements used

### 13.5 Enhancement Layer

After base video generation, the pipeline can add:
- Background music (royalty-free library or style packs)
- AI voiceover (SSML-controlled)
- Burned-in captions (word-timed)
- Brand watermark / logo overlay (from Brand Kit)
- Platform-specific encoding (resolution, codec, safe areas)

## 14. Publishing & Distribution

### 14.1 Social Account Connection

**OAuth redirect flow** (secure, industry-standard):

1. User clicks “Connect [Platform]” on `/social`
2. Frontend requests authorize URL from backend
3. Browser redirects to Google (YouTube) or Meta (Facebook/Instagram)
4. User approves permissions
5. Provider redirects to **backend callback** (not frontend)
6. Backend exchanges code, stores encrypted tokens, fetches channel/page info
7. Backend redirects user back to `/social?connected=youtube`
8. Frontend refreshes account list and shows success toast

**Security notes:**
- Frontend never handles OAuth `code` or tokens
- Backend signs and verifies CSRF `state`
- Tokens stored encrypted server-side
- Public API returns account metadata only (handle, display name, avatar) — never tokens

### 14.2 Publish Flow

On `/publish`, users can:

- Toggle which connected platforms receive the video
- Edit per-platform title, description, and tags
- Choose **Publish Now** or **Schedule** for a future date/time
- Confirm in a review modal before submission

### 14.3 Platform-Specific Behavior

| Platform | Publishes To | Requirement |
|----------|--------------|-------------|
| YouTube | User's channel | Google OAuth |
| Facebook | User's **Page** | Meta OAuth; Page admin access |
| Instagram | Professional account | Must be linked to connected Facebook Page |
| TikTok | User's TikTok account | Coming soon |

## 21. Security & Trust

### Authentication
- Email/password with secure password requirements
- Google OAuth sign-in
- JWT access + refresh token rotation
- Session persistence with secure token storage

### Social Account Security
- OAuth tokens encrypted at rest on backend
- CSRF protection via signed state parameter
- Per-project token scoping
- Soft disconnect (revoke without deleting history)

### Data Privacy
- Project access returns 404 for unauthorized resources (no existence leakage)
- API responses never include raw OAuth tokens
- Environment-based configuration (no hardcoded secrets in client)

### Platform Compliance
- Respects YouTube API audit requirements
- Meta App Review for Facebook/Instagram publishing
- Test/development mode restrictions during provider review periods
